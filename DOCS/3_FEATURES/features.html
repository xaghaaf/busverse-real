Authentication & Identity

Core

Every actor — passenger, driver, operator, admin, support — has a distinct authentication flow with role-based access.

Passenger

  • Phone OTP login (primary)
  • Email + password login
  • Google / social login
  • Guest checkout
  • Profile management
  • Saved passengers (family/friends)
  • Saved payment methods (tokenized)
  • Multi-device sessions
  • Logout all devices

Driver

  • Phone OTP + password login
  • Profile (license, photo, experience)
  • Document upload (license, ID)
  • KYC verification status
  • Shift availability toggle

Operator

  • Company signup (GST, PAN, bank)
  • KYC document upload
  • Admin approval workflow
  • Multiple sub-users per operator
  • Company profile management

Admin / Support

  • Email + password + 2FA
  • Role-based access control (RBAC)
  • IP whitelist (optional)
  • Session management

Cancellation & Refund

Core

Time-based refund policy with automated gateway refunds and full audit trail.

  • User-initiated cancellation
  • Operator-initiated cancellation
  • Platform-initiated cancellation
  • Partial cancellation (group)
  • No-show handling
  • Time-based refund policy
  • Auto refund via gateway
  • Refund webhook tracking
  • Refund history
  • Refund to original method (UPI→UPI, card→card)

Refund Policy

Time Before DepartureRefund
More than 24 hours100% (minus gateway fee)
12–24 hours90%
6–12 hours75%
2–6 hours50%
Less than 2 hours0%
Operator cancels trip100%
Platform cancels trip100% + compensation credit
