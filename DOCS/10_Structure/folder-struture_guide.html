SETUP GUIDE // v1.0

Folder Structure & Environment Setup

The complete guide to bootstrapping BusVerse Real on a fresh machine. Folder layout, config files, Docker services, env vars, and the Python bootstrap script that creates it all in one command.

Version: 1.0 Platform: Windows / macOS / Linux Runtime: Node 22 LTS Package manager: pnpm 9

Section 08

Bootstrap Script

bootstrap.py creates every folder and file documented above. Idempotent — running it twice is safe.

What it does
  1. Verifies tools — Node, pnpm, git, docker versions
  2. Creates 36 folders — apps, packages, docs, scripts, infra, tests
  3. Writes 25 files — all config, no overwrite by default
  4. Skips existing — never clobbers your work unless --force
  5. Prints next steps — the exact commands to run after
Flags
FlagEffect
--root PATHCreate in a specific directory (default: current)
--dry-runShow what would happen, write nothing
--forceOverwrite existing files (careful — this clobbers)
--skip-docsSkip creating the docs/ tree
--verifyTool version check only, no file creation

Idempotent by default: running it a second time after making changes is safe. It only creates what's missing.

The script is included in bootstrap.py at the project root. Read it before running — every file it writes is documented above.

Section 09

Run & Verify

From a fresh machine to a running API in 10 minutes.

Step 1 · Preview the bootstrap

cd D:\BUS_VERSE\BUS-VERSE-REAL
python bootstrap.py --dry-run
Shows every folder and file that would be created. Nothing is written.

Step 2 · Apply

python bootstrap.py

Step 3 · Install dependencies

pnpm install
Also runs lefthook install automatically via the prepare script.

Step 4 · Copy env files

Copy-Item .env.example .env
Copy-Item .env.example apps\api\.env
On macOS/Linux: cp .env.example .env and cp .env.example apps/api/.env

Step 5 · Start Docker services

pnpm docker:up
Start-Sleep -Seconds 5
docker ps
You should see 4 containers: postgres, redis, mailhog, adminer.

Step 6 · Initialize the database

pnpm --filter api prisma:generate
pnpm --filter api prisma migrate dev --name init
pnpm db:seed

Step 7 · Run the API

pnpm --filter api dev
API should be at http://localhost:4000.

Step 8 · Verify everything

# All four containers healthy
docker ps

# Redis responds
docker exec busverse-redis redis-cli ping    # → PONG

# Postgres responds
docker exec busverse-postgres pg_isready -U busverse   # → accepting connections

# Prisma can connect
pnpm --filter api prisma:studio
# → opens http://localhost:5555, shows `users` table with 1 seeded row

If all 4 checks pass, you're done. Write code, commit, push.

Section 10

Daily Workflow

After setup, this is what you type every day.

Morning

git switch develop
git pull
pnpm docker:up
pnpm --filter api dev

Making changes

git switch -c feat/your-feature
# ... edit files ...
pnpm lint              # biome check
pnpm typecheck         # tsc --noEmit via turbo
pnpm test              # vitest

Committing

git add -p             # stage hunks
git commit -m "feat(scope): message"
# pre-commit hook runs biome check
# commit-msg hook runs commitlint
git push

End of day

# Everything pushed
git status             # should say "nothing to commit"

# Stop Docker (optional — it eats RAM)
pnpm docker:down
Rule: No unpushed code at end of day.
Section 11

Troubleshooting

Every problem you'll actually hit. Fix included.

Common Issues
ProblemFix
python: command not foundAdd Python to PATH. On Windows, reinstall with "Add to PATH" checked.
pnpm: command not foundcorepack enable in Admin PowerShell, then restart terminal
node: command not foundAdd fnm env --use-on-cd | Out-String | Invoke-Expression to $PROFILE
Docker containers won't startOpen Docker Desktop app first, wait for the whale icon to stop animating
Port 5432 already in useAnother Postgres is running. Stop it or change the port in docker-compose.yml
Port 4000 already in useGet-NetTCPConnection -LocalPort 4000 | Select -ExpandProperty OwningProcess | Stop-Process
Prisma can't connectCheck .env DATABASE_URL matches docker-compose credentials exactly
LF/CRLF warnings on commitgit config core.autocrlf true — .gitattributes handles the rest
Lefthook hooks not runningpnpm lefthook install
Biome check fails on first commitRun pnpm format to auto-fix, then re-commit
pnpm install fails on argon2Windows needs build tools: choco install visualstudio2022buildtools
BOM in generated HTMLPython script writes UTF-8 without BOM by default — this is already handled
