01 · Six Apps Overview

BusVerse Real runs on six separate applications, each serving a distinct audience. They share a single backend but present completely different interfaces.

01
Passenger App
Web + PWA. For travelers to search, book, pay, track, and board.
02
Driver App
Mobile (React Native / Flutter). For drivers to stream GPS, scan QR, manage trips.
03
Operator Panel
Web. For bus operators to manage fleet, routes, schedules, drivers, and revenue.
04
Admin Panel
Web. For BusVerse team to approve, oversee, arbitrate, and control the platform.
05
Support Panel
Web. For support agents to handle tickets, chat, refunds, and escalations.
06
Shared Backend
Not an app — the API, WebSocket, database, and simulation that powers all five.

06 · Seat States

12 · Build Roadmap

The 18-month roadmap from MVP to full platform. Three phases — Launch, Growth, Scale.

Mermaid · Gantt

Phase 1 (Months 1–6): Core booking, payments, ticketing, driver app, operator + admin panels. The MVP that proves the model.

Phase 2 (Months 7–12): Corporate B2B, travel agents, loyalty, referral, dynamic pricing, dispute resolution. The growth engine.

Phase 3 (Months 13–18): Bus substitution, overbooking, government bus integration, advanced analytics. The scale layer.
